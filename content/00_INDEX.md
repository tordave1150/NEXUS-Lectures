## Important Corrections Flagged

1. [[Naive Bayes]] — DADS6003 worked example มี decimal slip `0.0092 → 0.092`; คำนวณที่ถูกต้องจากค่าบน slides ให้ **Female ≈56.5%**, ไม่ใช่ Male.
2. [[Cross Validation]] — `60/20/20 train-validation-test` เป็น three-way holdout split ไม่ใช่ cross-validation โดยตัวมันเอง.
3. [[Feature Scaling]] — z-score standardization **ไม่ได้ map ค่าให้อยู่ (-3,3)**; มัน center ด้วย training mean และ scale ด้วย training standard deviation โดย range ไม่ bounded.
4. [[Gradient Descent]] — ถ้า MSE นิยามเป็น $\frac1n\sum e_i^2$ gradient มี factor 2; หรือใช้ $\frac1{2n}\sum e_i^2$ เพื่อให้ gradient form ไม่มี factor 2.
5. [[Ordinary Least Squares and Normal Equation]] — complexity ของ explicit inverse ต้องระบุ dimension ให้ชัด; practical OLS มักใช้ QR/SVD/lstsq แทน explicit $(X^TX)^{-1}$.
6. [[Backpropagation]] — hidden-layer delta ทั่วไปต้อง sum contributions จาก downstream units; worked path formula ไม่ใช่ recursion ทั่วไป.
7. [[Decision Trees]] — แยก algorithm family (ID3/C4.5/CART) ออกจาก split criterion (entropy/information gain/Gini); Bagging/Boosting เป็น ensemble methods ไม่ใช่ pruning.
8. [[K-Nearest Neighbors]] — odd $k$ ลดโอกาส tie ในบาง binary settings แต่ไม่รับประกันว่าจะไม่มี tie ทุกกรณี.
9. [[ML Time-Series Feature Engineering]] — rolling target features ต้อง shift เพื่อไม่ให้ current/future target leak เข้า predictors.
10. [[Autocorrelation and ACF]] — $\pm2/\sqrt{T}$ เป็น approximate marginal reference ไม่ใช่ universal white-noise decision rule.
11. [[Dynamic Harmonic Regression]] — $|ACF1|>0.3$ ถูกเก็บเป็น rough rule of thumb ไม่ใช่ statistical law.
12. [[Intermittent Demand Forecasting]] — ADI/CV² cutoffs เป็น literature-derived classification heuristics ไม่ใช่ universal thresholds.
13. [[HDFS]] — HDFS เป็น write-once-oriented filesystem แต่ current architecture รองรับ append/truncate; "no append" เป็น legacy simplification.
14. [[Apache Hive]] — Hive indexing จาก lecture เป็น legacy feature และถูก removed ตั้งแต่ Hive 3.0.
15. [[Spark Transformations Actions and Lazy Evaluation]] — `reduceByKey` เป็น transformation ไม่ใช่ action.
16. [[Spark SQL and DataFrames]] — `SQLContext` เป็น Spark 1.x entry point; modern structured-data workflow ใช้ `SparkSession`.
17. [[Spark ML and MLlib]] — RDD-based `spark.mllib` อยู่ maintenance mode; DataFrame-based `spark.ml` เป็น primary ML API.
18. [[Apache Kafka]] — Kafka 0.9/ZooKeeper commands ใน lab เป็น legacy; Kafka 4.0+ ใช้ KRaft และไม่มี ZooKeeper mode.
19. [[K-Means Clustering]] — lab รวม Euclidean distances แล้วเรียก WSSSE; canonical SSE ต้องรวม **squared** distances.


20. [[Hypothesis Testing Fundamentals]] — directional examples in the lecture contain some H0/H1 inconsistencies; canonical hypotheses align the alternative with the research claim and include the boundary/equality in the null when required.
21. [[Permutation Tests]] — validity requires a null-consistent exchangeability/randomization scheme; not every arbitrary permutation is valid.
22. [[Pearson Correlation]] — correlation-strength cutoffs are rough heuristics, not universal scientific thresholds.
23. [[Inference for Pearson Correlation]] — classical t inference is for iid paired observations under a bivariate-normal model, not two independent X/Y samples.
24. [[Coefficient of Determination R-Squared]] — multiple correlation satisfies $R=\sqrt{{R^2}}$; in simple regression with intercept $R=|r|$.
